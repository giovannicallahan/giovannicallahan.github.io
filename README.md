# callgio.github.io

Personal website of Giovanni Callahan: who I am, my research, and my two apps,
[NeuroApp](https://callgio.github.io/neuroapp/) and
[CogViz Research Studio](https://cogviz-research-studio.streamlit.app/).

Live at **https://callgio.github.io**. Short links: `/brain` opens NeuroApp, `/cogviz` opens CogViz.

## Editing

The pages are plain HTML generated by `build.py`, so the header and footer stay identical
everywhere. To change any wording, edit the text in `build.py`, then run:

```bash
python3 build.py
```

Styles live in `css/site.css`; the animations and form handling live in `js/site.js`.
There are no dependencies, no build tools beyond Python, and no trackers.

## Connecting the contact and feedback forms

1. Create a free account at https://formspree.io and add a new form that sends to your email.
2. Copy the form ID (the part after `/f/` in the form's endpoint, e.g. `xyzabcd`).
3. Paste it into `FORMSPREE_ID` near the top of `js/site.js`, commit and push.

Until then, both forms say they are not connected and the Send button stays disabled.
