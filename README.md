# giovannicallahan.github.io

Personal website of Giovanni Callahan: who I am, my research, and my two apps,
[Gyrafold](https://gyrafold.com/) and
[CogViz Research Studio](https://cogviz-research-studio.streamlit.app/).

Live at **https://giovannicallahan.github.io**. Short links: `/brain` opens Gyrafold, `/cogviz` opens CogViz.

## Editing

The pages are plain HTML generated by `build.py`, so the header and footer stay identical
everywhere. To change any wording, edit the text in `build.py`, then run:

```bash
python3 build.py
```

Styles live in `css/site.css`; the animations and form handling live in `js/site.js`.
There are no dependencies, no build tools beyond Python, and no trackers.

## Connecting the contact and feedback forms

1. Create a free account at https://formspree.io and add a new form that sends to your email.
2. Copy the form ID (the part after `/f/` in the form's endpoint, e.g. `xyzabcd`).
3. Paste it into `FORMSPREE_ID` near the top of `js/site.js`, commit and push.

Until then, both forms say they are not connected and the Send button stays disabled.

## Pasta choice study (`/study/`)

`study/index.html` is a self-contained online pilot for the Dual-Depletion Project (Feghhi lab):
a pasta-choice task under a 2-digit vs 6-digit memory load. It is not generated by `build.py`,
is linked from the menu as "Study" (set in `NAV` in `build.py`), is not in the sitemap,
and asks search engines not to index it.

- Settings are in the `CONFIG` block at the top of its script.
- Finished sessions are saved to the `pilot_sessions` table of the Supabase project
  `Cognitive_Study`. The page can add rows but cannot read them.
- `/study/?debug=1` runs a one-minute version that saves nothing.
- The consent text shows a draft banner until `CONSENT_IS_DRAFT` is set to `false`
  (do that only after IRB approval of the online wording).
